## 팀 소개 웹페이지

`index.html`을 브라우저에서 열면 팀 소개 페이지를 볼 수 있습니다. 별도의 패키지 설치 없이 실행되며, 모바일 화면도 지원합니다.

- `index.html`: 밸런스 게임, 비행기 좌석 배치도, 팀원 소개와 탑승권
- `styles.css`: 비행기 객실, 회색 일반 좌석, 탑승권과 반응형 레이아웃
- `script.js`: 밸런스 게임 선택, 팀원 매칭과 탑승권 표시

### 인터랙션 흐름

1. 첫 화면에서 `최태원·이재용`, `교수님 두 분`, `카리나·장원영` 중 함께 앉고 싶은 두 사람을 선택합니다.
2. 바로 좌석 배치도로 이동하며 선택한 두 사람 사이의 익명 빈 좌석이 강조됩니다. 이 단계에서는 탑승권이 열리지 않습니다.
3. 빈 좌석을 클릭하면 이름, 나이, 좋아하는 음식, 학과와 사진이 담긴 탑승권이 공개됩니다.
4. 세 좌석은 선택 전까지 `?` 표시로 이름과 얼굴을 숨깁니다. 나머지 일반 좌석은 인물이나 캐릭터 없이 비어 있는 회색 좌석으로 표시됩니다.
5. 공개한 팀원의 카드만 아래에 나타납니다. 밸런스 게임을 다시 시작하면 익명 상태로 돌아갑니다.

세 그룹은 일반 승객 한 줄씩을 사이에 두고 분리했습니다: 전형원은 앞쪽 오른편 01E, 김찬영은 중간 왼편 03B, 손용국은 뒤쪽 오른편 05E입니다. 각 그룹의 양옆 특별 승객은 그대로 유지됩니다.
