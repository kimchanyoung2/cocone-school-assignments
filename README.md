# cocone AIR · BALANCE FLIGHT

밸런스 게임, 비행기 좌석 선택, 팀원 탑승권을 결합한 인터랙티브 팀 소개 랜딩 페이지

## 1. 프로젝트 소개

본 프로젝트는 전형원, 김찬영, 손용국 세 명을 소개하기 위해 제작한 비행기 콘셉트의 웹사이트입니다.

사용자는 첫 화면에서 `최태원·이재용`, `교수님 두 분`, `카리나·장원영` 중 장거리 비행을 함께하고 싶은 두 사람을 고릅니다. 선택 직후에는 정답을 보여주지 않고 비행기 좌석 배치도로 이동합니다. 선택한 두 사람 사이에 놓인 `?` 좌석을 직접 눌러야 비밀 탑승객의 얼굴과 정보가 가천에어 탑승권으로 공개됩니다.

단순히 팀원 카드를 나열하는 대신, 선택과 발견 과정을 거쳐 자연스럽게 팀원을 만나도록 만든 것이 프로젝트의 핵심입니다.

## 2. 프로젝트를 만들게 된 이유

일반적인 팀 소개 페이지는 이름과 전공을 처음부터 모두 보여주기 때문에 정보를 빠르게 확인할 수 있지만, 사용자가 직접 참여할 요소는 적습니다.

저희 팀은 팀원 소개 자체를 짧은 게임처럼 경험하게 만들고 싶었습니다. 누구 옆에 앉을지 고민하는 밸런스 게임, 실제 항공기처럼 구성한 좌석 배치도, 정답을 숨긴 익명 좌석을 순서대로 연결해 호기심이 이어지도록 기획했습니다.

선택한 좌석에서 팀원이 공개되는 순간에는 실제 여행의 시작처럼 탑승권을 보여줍니다. 출발지는 `GCS`, 목적지는 `SUP · 스타트업 창업`로 설정해 학교에서 출발해 더 큰 목표를 향해 간다는 의미도 담았습니다.

## 3. 프로젝트 목표

- 첫 화면에서 바로 참여할 수 있는 밸런스 게임 제공
- 선택 직후 정답을 노출하지 않는 익명 좌석 구조 구현
- 비행기 좌석을 클릭하는 과정을 통해 팀원 정보 공개
- 세 팀과 양옆 인물의 관계를 좌석 배치로 명확하게 표현
- 실제 항공권처럼 보이는 코코네 에어 탑승권 디자인
- 영문 이름, 학과, MBTI, 생일, 취미를 같은 형식으로 제공
- 데스크톱과 모바일에서 모두 사용할 수 있는 반응형 화면 구성
- GitHub 저장소, Project, Milestone과 배포 페이지 연결

## 4. 핵심 디자인 원칙

### 4.1 Choice First

사용자가 처음부터 팀원 정보를 읽게 하지 않고 먼저 옆자리를 선택하게 했습니다. 세 개의 선택지는 큰 얼굴 이미지와 명확한 이름으로 구성해 고민 없이 바로 참여할 수 있도록 했습니다.

### 4.2 Anonymous Reveal

밸런스 게임에서 항목을 선택해도 탑승권은 즉시 열리지 않습니다. 좌석 배치도로 이동한 뒤 강조된 `?` 좌석을 눌러야 탑승객의 얼굴과 이름이 공개됩니다. 이 한 단계의 지연이 결과에 대한 기대감을 만듭니다.

### 4.3 Aircraft Seat Composition

세 팀을 한곳에 모으지 않고 객실의 앞쪽, 중간, 뒤쪽으로 분리했습니다. 각 그룹 사이에는 빈 회색 좌석 줄을 배치해 누구의 좌석인지 쉽게 구분되도록 구성했습니다.

### 4.4 Boarding Pass Identity

공개 결과는 일반 팝업 대신 코코네 에어 탑승권 형태로 디자인했습니다. 큰 얼굴 사진, 노선, 좌석 번호와 핵심 정보가 한 장 안에서 빠르게 읽히도록 시각적 우선순위를 정했습니다.

### 4.5 Information Clarity

탑승권에는 필요한 정보만 남겼습니다. 모든 팀원에게 동일하게 `영문 이름 / 학과 / MBTI / 생일 / 취미`를 표시하며, 정보별 칸을 나누어 긴 취미 목록도 읽기 쉽게 구성했습니다.

## 5. 인터랙션 흐름

### Step 1 — Balance Game

첫 화면에서 장거리 비행을 함께하고 싶은 두 사람을 선택합니다.

- 최태원 · 이재용 옆
- 교수님 두 분 옆
- 카리나 · 장원영 옆

### Step 2 — Seat Map

선택하면 탑승권이 바로 나타나지 않고 비행기 좌석 배치도로 이동합니다. 선택과 연결된 익명 좌석에는 파란색 강조 효과가 적용됩니다.

### Step 3 — Anonymous Seat

강조된 좌석은 팀원의 사진이나 이름 대신 `?`와 좌석 번호만 표시합니다. 사용자가 좌석을 클릭할 때까지 탑승객의 정체는 공개되지 않습니다.

### Step 4 — Passenger Reveal

익명 좌석을 클릭하면 좌석에 팀원의 얼굴과 이름이 나타나고, 동시에 가천에어 탑승권이 열립니다.

### Step 5 — Replay

`밸런스 게임 다시 하기` 버튼을 누르면 모든 팀원 좌석이 다시 익명 상태로 돌아갑니다. 사용자는 다른 선택지를 골라 나머지 팀원도 확인할 수 있습니다.

## 6. 좌석 배치

| 객실 위치 | 양옆 인물 | 가운데 탑승객 | 좌석 |
| --- | --- | --- | --- |
| 앞쪽 오른편 | 최태원 · 이재용 | 전형원 | 01E |
| 중간 왼편 | 교수님 두 분 | 김찬영 | 03B |
| 뒤쪽 오른편 | 카리나 · 장원영 | 손용국 | 05E |

지정된 인물과 팀원 좌석을 제외한 나머지 자리는 인물이나 캐릭터가 없는 회색 빈 좌석으로 표현했습니다.

## 7. 코코네 에어 탑승권

탑승권은 학교에서 미래의 목표로 출발하는 이미지를 담고 있습니다.

- Airline: `코코네 에어 / cocone AIR`
- From: `GCS / GACHON CAMPUS`
- To: `SUP / 스타트업 창업`
- Flight: `009`
- Passenger Data: 영문 이름, 학과, MBTI, 생일, 취미

얼굴 사진은 탑승권 안에서 가장 먼저 보이도록 크게 배치했습니다. 데스크톱에서는 최대 `210 × 210px`, 모바일에서는 `138 × 150px` 크기로 표시됩니다.

### 전형원

관광경영학과에 재학 중이며, 스쿠버다이빙을 좋아합니다. 코코네 에어에서는 최태원과 이재용 사이의 01E 좌석에 배정됩니다.

### 김찬영

경영학과에 재학 중이며 러닝을 좋아합니다. 마케팅과 CRM에 관심이 있고, 장기적으로 소상공인의 고객관리와 매출 문제를 해결하는 컨설팅에 도전하는 것이 목표입니다. 코코네 에어에서는 교수님 두 분 사이의 03B 좌석에 배정됩니다.

### 손용국

행정학과에 재학 중이며 농구, 축구, 게임, 드라이브를 좋아합니다. 코코네 에어에서는 카리나와 장원영 사이의 05E 좌석에 배정됩니다.

## 9. 주요 특징

- 선택형 밸런스 게임으로 시작하는 랜딩 페이지

- 선택한 좌석을 알려주는 강조 효과
- 좌석 클릭 후 얼굴과 이름이 나타나는 공개 효과
- 큰 얼굴 사진이 들어간 가천에어 탑승권
- `GCS → SUP` 노선 설정
- 팀원별 좌석 번호와 일관된 정보 형식

| --- | --- |
| `index.html` | 밸런스 게임, 좌석 배치도, 탑승권과 팀원 소개 구조 |

## 12. GitHub 협업 방식

GitHub Issues와 GitHub Projects를 이용해 작업을 관리합니다.

- `Backlog`: 이후 검토하거나 추가할 작업
- `Ready`: 바로 시작할 수 있는 작업
- `In Progress`: 현재 작업 중인 항목
- `Done`: 구현과 확인이 끝난 항목

작업은 Issue 단위로 작성하고 관련 Milestone에 연결해 진행 상황을 확인할 수 있도록 구성했습니다.
