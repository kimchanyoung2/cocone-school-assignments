# Together · 팀 소개

전형원, 김찬영, 손용국을 소개하는 팀 웹페이지입니다.

## 팀원 정보

| 이름 | 전공 | 나이 | 대학교 | 거주지 |
| --- | --- | --- | --- | --- |
| 전형원 | 관광경영학과 | 24세 | 강원대학교 | 김천시 |
| 김찬영 | 경영학과 | 23세 | 가천대학교 | 서울 |
| 손용국 | 행정학과 | 24세 | 가천대학교 | 서울 |

팀 내 역할과 담당 업무는 아직 정해진 정보가 없어 기재하지 않았습니다.

## 팀 소개 웹페이지

`index.html`을 브라우저에서 열면 팀 소개 페이지를 볼 수 있습니다. 별도의 패키지 설치 없이 실행되며, 모바일 화면도 지원합니다.

- `index.html`: 팀원 소개 내용과 GitHub 링크
- `styles.css`: 색상, 카드 디자인, 반응형 레이아웃
- HTML과 CSS만 사용하며 JavaScript나 프레임워크는 사용하지 않습니다.
- 팀원 정보가 바뀌면 이 README의 표와 `index.html`의 팀원 카드를 함께 수정해 주세요.
- `together`는 페이지 디자인용 제목입니다.
