## 팀 소개 웹페이지

`index.html`을 브라우저에서 열면 팀 소개 페이지를 볼 수 있습니다. 별도의 패키지 설치 없이 실행되며, 모바일 화면도 지원합니다.

- `index.html`: 밸런스 게임, 비행기 좌석 배치도, 팀원 소개와 탑승권
- `styles.css`: 비행기 객실, 회색 일반 좌석, 탑승권과 반응형 레이아웃
- `script.js`: 밸런스 게임 선택, 팀원 매칭과 탑승권 표시

### 인터랙션 흐름

1. 첫 화면에서 `최태원·이재용`, `교수님 두 분`, `카리나·장원영` 중 함께 앉고 싶은 두 사람을 선택합니다.
2. 선택한 두 사람 사이에 앉은 팀원이 각각 전형원, 김찬영, 손용국으로 연결됩니다.
3. 선택 결과는 이름, 나이, 좋아하는 음식, 학과와 사진이 담긴 탑승권으로 표시됩니다.
4. 좌석 배치 화면에서는 세 팀원이 모두 가운데 좌석에 앉고, 양옆 특별 승객 외의 좌석은 회색으로 표시됩니다.
5. 객실의 팀원 좌석이나 아래 팀원 카드의 `탑승권 보기`를 눌러 탑승권을 다시 열 수 있습니다.
